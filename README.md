# narayangautam.github.io

My personal portfolio with all the things I have worked on [Portfolio](https://narayangautam.github.io/).

Built with Vite, React, TypeScript, and Tailwind CSS. Deployed automatically on push to `main`.

### GitHub Pages setup (required once)

If the live site is blank, GitHub is probably serving source files instead of the built app.

1. Repo **Settings → Pages**
2. **Build and deployment → Source:** Deploy from a branch
3. **Branch:** `gh-pages` / **Folder:** `/ (root)`
4. Save, wait 1–2 minutes, then open https://narayangautam.github.io/

The workflow builds with Vite and pushes `dist/` to the `gh-pages` branch.
